# instagram-agent-skill

Бесплатен пакет од **12 skill-ови за Claude** за водење Instagram профил: содржина, коментари, пораки, план и анализа.
Работи за **секој профил**. Пред почеток skill-от те интервјуира, прави бриф на профилот, и сите останати skill-ови пишуваат од тој бриф: ист тон, ист јазик, иста публика.

## Skill-ови

| Skill | Што прави |
|---|---|
| `ig-brief` | Интервју и бриф на профилот (основа за сите, **почни од тука**) |
| `ig-hooks` | Hook-ови од база на 26 формули |
| `ig-reel-script` | Скрипта за Reel со тајмкодови, текст на екран и визуели |
| `ig-caption` | Опис и хаштагови |
| `ig-carousel` | Карусел слајд по слајд |
| `ig-stories` | Секвенца stories со анкети и прашања |
| `ig-content-plan` | Неделен/месечен план |
| `ig-repurpose` | Стара или туѓа објава претворена во нова за твојот профил |
| `ig-comments-read` | Читање и сортирање коментари (продажни можности најгоре) |
| `ig-comment-reply` | Нацрти одговори на коментари |
| `ig-dm-reply` | Нацрти одговори на пораки |
| `ig-analytics` | Анализа од Insights и што да се смени |

## Структура

```
skills/          12 skill-ови, секој во своја папка со SKILL.md
hooks.json       26 формули за hook-ови
dist/            секој skill спакуван како .zip за прикачување
README.md
LICENSE          MIT
```

## Поставување

1. Симни ги `.zip` фајловите од папката `dist/` (или клонирај го репозиториумот).
2. Во Claude отвори ги поставките, делот за **Skills**, и прикачи го секој `.zip` посебно.
3. Нов разговор: *„Направи бриф за мојот Instagram профил“* → се вклучува `ig-brief`.
4. Потоа само барај: *„напиши скрипта за Reel за …“*, *„одговори на овие коментари“*, *„план за следната недела“*.

Брифот се чува во проектот (`profiles/<handle>.md`), во Notion, или го чуваш ти и го залепуваш.

## Што НЕ прави (искрено)

- **Не објавува сам.** Instagram нема директна врска за објавување. Ти копираш и објавуваш.
- **Не праќа пораки и не одговара сам.** Сè е нацрт што ти го одобруваш.
- **Не измислува бројки ни резултати.** Анализата бара вистински податоци од Insights.
- **Не прави раст сам по себе.** Раст прави добра содржина објавувана редовно; skill-овите ти го скратуваат времето за тоа.
